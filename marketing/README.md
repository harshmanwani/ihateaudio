# Marketing execution

The strategy lives in [MARKETING.md](../MARKETING.md) at the repo root. This folder holds
the week-to-week execution: hit lists of live threads worth answering, drafted posts and
comments, and pitch copy.

One file per working session, named `<channel>-<date>.md`, so it stays obvious what was
current when it was written. Threads go stale fast — Reddit archives at six months, and
a draft written against a thread's comments is only accurate the week it was made.

| File | What it is |
|---|---|
| [reddit-hitlist-2026-08-01.md](reddit-hitlist-2026-08-01.md) | First hit list: 6 live threads plus an r/SideProject post, each drafted against what the thread actually says |

Drafts here are starting points, not paste-ready text. Rewrite in your own voice before
posting: identical copy across threads is itself a spam signal, and the disclosure
("I built this") is not optional.
